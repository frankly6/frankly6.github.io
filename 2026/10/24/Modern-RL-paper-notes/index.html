R2-Dreamer

默认读者拥有 Model-based RL 与 Dreamer 系列文章的基础

R2-Dreamer —— ICLR 2026 Poster
知乎分析 / 翻译

随着时代的发展, Model-based RL 的 RL 问题已经大部分被解决, 而 Model 问题还仍然存在

总的来说, Model 的目标是现实环境的简化表征(representation),
我们可以用监督学习来得到这种表征, 但它是最优的吗？

什么是最优表征？对于 Model 而言, 关心我们想要关心的世界动态与交互, 忽略背景(background)与 task-irrelevent 的东西, 这和纯粹的监督学习目标可能有较大偏差

近年来最成功的方法就是 Dreamer V3, 原来它发了 Nature, 怪不得这么多 follow work
Dreamer-like 的文章通过优化像素级重建目标来学习表征, 以 DreamerV3 为例, 原始图像为 \(x\), 之前的 Seq Model 隐状态为 \(h\), 先学表征 Model \(z \sim q_\phi(z|h,x)\), 再学 Decoder \(\hat x \sim p_\phi(\hat x|h,z)\), 然后做类似 ELBO 的东西来优化重建, 也可以说这种方法是 Decoder-based 的。
这种做法会在什么任务上折戟？在一些 small but task-critical objects 存在的任务上会失败

这是 Atari 100k benchmark 中的 Venture 游戏, 人物是那个 1x1 pixel 的小点, 有四个开口的房间需要你探索, 进入其中会转变地图
有很多因素在阻碍 Dreamer 架构对我们人物的关心, 例如误差重建中会产生 \(\| x - \hat x \|^2\) 这样的项, 读入的 CNN 会缩放和下采样, KL 正则化会取舍预测, 预测背景多么简单, 它不会动又足够明显, 相反, 在按下移动键后像素点飞速移动怎么能看见呢？

当然这个例子有点极端, 我倾向于当模型已经吃完重建背景的 easy-lunch 后会去关心一下移动键到底造成了什么影响, 不过在这里 CNN 的下采样可能都是致命的

Venture 的测试得分, 六列分别为 Random, Gamer, Human Record, PPO, MuZero, Dreamer 的得分, 在这里是 PPO 最优

因此, 虽然 pixel-reconstruction 很自然并且常见, 但我们有时候需要抛弃它, 抛弃这自然的监督方法
为了训练 Model, 我们需要自监督学习(Self-Supervised Learning, SSL)方法了, 要构建某种 self-supervised losses

在这里需要引入 数据增强(Data Augmentation, DA) 技术, 也引出了表征崩溃(representation collapse)的问题
数据增强的思想是这样的, 例如我们希望 Model 不要学习什么 "背景颜色对运动的影响", 于是我们在输入做颜色抖动(color jittering), 并且强制颜色抖动前后模型学习的表征是一样的。我们 "增强" 什么其实是希望模型 "不去学习" 某些东西

这个方法有两个问题,
一是 Ad-hoc, 如果我们做一个红灯停绿灯行的 Model, 显然不能 color jittering; 如果我们的问题也有 small but task-critical objects, 那就(可能)不能做 random shifting, etc.
更大的问题在于表征崩溃, 所有 DA 方法处于一种 "既要又要" 的状态, 而对于模型最好的摆烂方法就是——对所有输入都输出同样的向量

在两类方法之外, 更多的修修补补来源于辅助目标(auxiliary objectives) / 辅助输入, 可以预测奖励, 可以额外预测 "事件"(画面的大幅改变)From Observations to Events, ICLR 2026, 可以加入一个冻结的视觉分割模型并通过 few-shot 标注给后续 model 输入直接把主角 mask 给出来OC-STORM, ICLR 2026

讲到这里, 我们还没有说文章想做什么, 简单来说是 DA-free 的内部正则化

我们可以说 R2-Dreamer 是把 DreamerV3 与 Barlow Twins 做了个 A+B, 也可以说它 "开创了 Decoder-free + DA-free 的 Model-based RL 范式, 伟大之作, Openreview 8 8 4 4 实至名归"

所以 Barlow Twins 是什么？
Barlow Twins 是篇 SSL 领域文章, 被引量 4000+
之前的 SSL 文章是如何避免坍塌的？负样本、不对称结构、stop-gradient、etc.
本文在数学上更加本质, 首先, SSL 的核心, 让同一张图像的两种增强视图产生一致的特征, 要保留

然后, 重新审视, 坍塌是什么? 一种常见的坍塌, 就是很多特征维度实际上只剩下同一个信号, 维度的相关系数接近 1, 对于图像的两种视图, 计算相关性矩阵, 对非对角元素(不同的特征)施加平方惩罚, 例如 \(\mathcal L_{\mathrm{redundancy}} =\lambda\sum_{i\ne j}C_{ij}^{2}\), 其中 \(C_{ij} =\dfrac{\operatorname{Cov}(a_i,b_j)} {\sigma_{a_i}\sigma_{b_j}} \in[-1,1]\) 就可以防止特征维度的直接复制、放大复制、反号复制
对于相关性矩阵的对角元素(两视图对应的特征), 我们要求其相关性接近 1, 于是 \(\mathcal L_{\mathrm{invariance}}=\sum_i(1-C_{ii})^2\)

往深了扯, 这叫做去冗余, "神经科学家 Horace Barlow 提出, 感官输入包含大量冗余, balabala"
往浅了讲, 这是不是类似白化操作加上一个对齐?

Barlow Twin 的做法是对一个包含 \(N\) 张图像的 batch, 每张图像分别做两次随机增强，例如裁剪、颜色扰动、模糊, 得到两种视图, \(x_b \longrightarrow \begin{cases} y_b^A=t_A(x_b)\\ y_b^B=t_B(x_b) \end{cases}\), 然后经过共享参数的编码器和投影器 \(z_b^A=g_\theta(f_\theta(y_b^A)),\; z_b^B=g_\theta(f_\theta(y_b^B))\), 在两个(Twin) \(z\) 上算 \(\mathcal L_{\text{BT}} = \mathcal L_{\mathrm{redundancy}} + \mathcal L_{\mathrm{invariance}}\)

在 R2-Dreamer 的语境下呢? 我们不是说好 DA-free 了吗?

我们看看 图像/观察 是怎么在网络里处理流动的

\(\boldsymbol o\) 是原始的图像观测, \(\boldsymbol e\) 是图像的特征, 已经是一种表征了, 我们做网络 \(e = f_\phi(o)\) 得到
而 \(\boldsymbol z\) 才是世界模型的潜状态, ​它包含了历史信息 \(h\), 有网络 \(z = q_\phi(z|h,e)\), 内含了 Dynamic

如果是 Dreamer, 我们要返回直到 \(\hat {\boldsymbol o}\) 为止, 但这是 R2-Dreamer, 我们返回 \(k\) 做 Barlow Twin 就行了, 这里的 \(\boldsymbol s = (\boldsymbol h, \boldsymbol z)\), 然后 Projector 比 Decoder 轻量多了, 只是一层不带 bias 的 MLP, \(k = f_\phi(s)\)

对于 Loss, 作者专门把 DreamerV3 的 Reconstruction Loss 摘了出来, 换成 Barlow Twin Loss 就行了

对于后面 RL 的 Actor-Critic 部分, 相较于 DreamerV3 没看到任何改动

这里的衰减 \(\gamma = 1- \frac{1}{\rm horizon}\), 最终会乘以 0/1 的 done 来, 额, 额外把 done 的活完成 然后 critic 学 λ-return, 通过 self._lambda_return 从后往前卷过来, \(R_t = r_{t} +\gamma c_{t} \left[(1-\lambda)V_{t+1}+\lambda R_{t+1}\right]\), 其中 \(c\) 是预测继续概率, 没有纯粹用 \(V\), 因为后续想象轨迹的奖励修正估计可能更准一点？默认 \(\lambda = 0.95\)

value 的 loss 还要向 target network 靠拢, \(\mathcal L_V = \mathbb{E} \left[ w_t\left( -\log p_\phi(G_t\mid f_t) -\log p_\phi(V_{\mathrm{slow},t}\mid f_t) \right) \right]\)

一些细节是 step 末尾加 0 去 0 以匹配价值分布形状 / 给 imagined 的最后一步补上未来

真实的 replay step 可以在训练 Critic 外训练 RSSM 与 encoder, 对于每个真实 step 有真实的 reward, done/last

此时 \(R_t^{\mathrm{replay}} = r_{t}^{\mathrm{real}} +\gamma(1-\mathrm{term}_{t}) \left[ (1-c_{t+1})\,\mathrm{boot}_{t+1} +c_{t+1}R_{t+1}^{\mathrm{replay}} \right]\), 这里的 \(\rm boot\) 是 \(V\) 和 0 的 "混合物"

每次 _cal_grad() 都会执行一次 imagined rollout 部分和一次 replay value learning 部分, 两者的损失最后一起汇总, 统一 backward(), 但是训练样本量不是 1:1 的, 大概是 15:1 左右, 训练范围也不同

clone_and_freeze() 方法创建模型与原网络共享参数数据的副本, 因为是共享与冻结, 不用实时同步
与 .detach() 的区别是可以对上游网络求梯度
gpt 告诉我, 这里的 freeze 大多可以用原网络配合 no_grad() 替代……
